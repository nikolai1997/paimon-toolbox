# 0.1.6 大地图

- 左侧“大地图”入口打开米游社官方原神地图，支持官方页面提供的点位筛选、采集标记和路线功能。
- 地图顶部账号左侧可弹出独立地图浮窗，默认置顶、支持拖动和缩放，也可取消置顶或返回主窗口。浮窗复用同一网页，切换到云原神时继续保留；关闭浮窗不会切换当前栏目。
- 使用当前工具箱账号的网页登录 Cookie；不向地图提供 SToken，不添加原生凭据读取桥。
- 进入地图前注入 Cookie，离开地图、退出或切换账号时清除独立的非持久化网页会话。
- 每次创建会话时，在官方地图脚本启动前写入操作引导的完成标记，避免重复弹出新手、区域与分层等引导；不持久化整个网页会话。
- 未登录可浏览公共地图；“登录米游社”前往现有扫码登录入口。
- 刷新和重试重新读取当前凭据；页面加载失败、超时或 WebKit 进程退出均显示重试入口。
- 本版本不额外轮询用户地图接口。标记的保存与读取由官方页面处理，不会导入为本地养成进度，也不等于自动识别游戏内实际采集行为。

## 验收

1. 未登录时打开地图，确认公共地图、缩放和筛选正常。
2. 扫码登录后进入地图，确认官方页面识别账号，并显示该账号已有标记与路线。
3. 在手机米游社标记一个点位，等待官方保存后刷新工具箱地图，核对记录。
4. 在工具箱地图取消或添加标记，在手机刷新并核对。
5. 切换账号、退出登录后，确认旧账号个人标记不再可见。
6. 断网、重试和快速切换页面时，确认没有黑屏或遗留的旧账号会话。

需要真实账号确认步骤 2-5；编译和策略单元测试不代表已完成官方登录兼容性验证。

可通过 `PAIMON_LIVE_MAP_CHECK=1 swift test --filter OfficialMapTests` 显式检查公开地图；此测试使用游客会话，验证地图图层已初始化且至少一张真实底图瓦片加载完成。普通测试运行会跳过网络检查。
